# Personal blog

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Cloudflare Worker + D1 is required. Frontend implementation is delegated: Worker-rendered HTML, CSS and small native JavaScript modules, with a Markdown administration interface.

## Users

The owner publishes a mixture of technical and personal writing. Readers browse, search, and read those posts on desktop and mobile.

## Product Purpose

A personal home for writing, with a comfortable public reading experience and a straightforward private publishing workflow.

## Capabilities and Constraints

- Public posts, category filtering, chronological archive, search and an about page.
- Password-protected Markdown administration: drafts, preview, publish, edit and site settings.
- Light and dark appearances; keyboard and mobile access.
- Worker handles requests and rendering; D1 stores content and metadata.
- The user delegated implementation and visual direction, and requested the installed design skills be used together.

## Evidence on Hand

The user will provide the blog name, byline, articles and images. Those materials have not arrived. Configuration fields stay editable, and preview fixtures must be clearly marked as demonstration content rather than the owner's history.

## Product Principles

- Published writing is readable without JavaScript.
- Drafts and private administration are never exposed through public search or feeds.
- Writing work survives recoverable errors; publishing reports the actual result.
- Design supports both technical and personal content without assigning an invented identity to the author.

## Open Decisions

Final blog name, author byline, biography, images, domain, GitHub repository and production deployment account are not yet supplied.
